**Nekto's Downloader**

A simple desktop application for downloading videos from YouTube and other supported platforms.

Built with Python and powered by yt-dlp.

---

✨ Features

- 🎬 Download videos from supported platforms
- 🎵 Download audio from supported sources
- ⚙️ Choose video/audio quality
- 📁 Select the output folder
- 🚀 Simple and lightweight interface
- 🔧 Uses "yt-dlp" for media extraction
- 🎞️ Uses FFmpeg for media processing and merging

---

🛠️ Technologies

- Python 3.12
- yt-dlp
- FFmpeg
- PyInstaller
- Tkinter / application interface

---

📦 Installation

From source

Clone the repository:

git clone https://github.com/YOUR_USERNAME/Nektos-Downloader.git
cd Nektos-Downloader

Create a virtual environment:

python -m venv .venv

Activate it on Windows:

.venv\Scripts\activate

Install dependencies:

pip install -r requirements.txt

Run the application:

python main.py

---

🖥️ Windows

A standalone Windows installer is available in the Releases section.

The packaged version includes the required Python runtime and application dependencies, so Python does not need to be installed separately.
